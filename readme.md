# BugBank – E2E Test Automation with Cypress

This project contains End-to-End (E2E) automated tests for the BugBank web application using Cypress and TypeScript.

## Project Goals

The goal of this project is to demonstrate test automation best practices, including test organization, Page Object Model, test data management, and validation of critical user flows.

## Test Scenarios Covered

* User registration
* Login
* Transfer between accounts
* Balance validation
* Error message validation
* Negative test scenarios
* Business rule validation

## Test Automation Architecture

This project uses:

* Cypress for E2E testing
* TypeScript
* Page Object Model (POM)
* Fixtures for test data
* Custom commands
* Organized test structure

## How to Run the Tests

1. Install dependencies:
   npm install

2. Run Cypress:
   npx cypress open

3. Run in headless mode:
   npx cypress run
